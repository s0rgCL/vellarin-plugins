# Google Search Console through Vellarin Hub

Google Search Console exposes 14 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Get Site
- Get Sitemap
- Get Site Verification Resource
- Get Site Verification Token
- Inspect URL
- List Sitemaps
- List Sites
- List Site Verification Resources

**Writes (wait for the owner's approval, then run once)**
- Add Site
- Delete Site
- Delete Sitemap
- Submit Sitemap
- Verify Site Ownership

Page: https://hub.vellarin.ai/apps/google_search_console
