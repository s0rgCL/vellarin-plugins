# Google Photos through Vellarin Hub

Google Photos exposes 13 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Get Album
- Download Photos Media Item
- List Albums
- List Media Items (App-Created Only)
- List Shared Albums (Deprecated)
- Search Media Items

**Writes (wait for the owner's approval, then run once)**
- Add Enrichment
- Batch Add Media Items
- Batch Create Media Items
- Batch Get Media Items
- Create Album
- Update Album
- Update Media Item
- Upload Media

Page: https://hub.vellarin.ai/apps/googlephotos
