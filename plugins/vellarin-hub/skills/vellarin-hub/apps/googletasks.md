# Google Tasks through Vellarin Hub

Google Tasks exposes 16 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Get Task
- Get task list
- List All Tasks Across All Lists
- List task lists
- List Tasks

**Writes (wait for the owner's approval, then run once)**
- Batch Execute Google Tasks Operations
- Bulk Insert Tasks (Deprecated)
- Clear tasks
- Create a task list
- Delete task
- Delete task list
- Insert Task
- Move Task

Page: https://hub.vellarin.ai/apps/googletasks
