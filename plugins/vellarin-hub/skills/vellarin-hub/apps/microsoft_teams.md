# Microsoft Teams through Vellarin Hub

Microsoft Teams exposes 237 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Get all chats
- Get all chat messages (Deprecated)
- Download channel message hosted content
- Download chat message hosted content
- Download drive item
- Download shared drive item
- Get call operation
- Get team channel

**Writes (wait for the owner's approval, then run once)**
- Add chat member
- Add User to Group
- Add member to channel
- Add member to team
- Add tab to channel
- Add member to team
- Add team members (bulk)
- Add workbook table column

Page: https://hub.vellarin.ai/apps/microsoft_teams
