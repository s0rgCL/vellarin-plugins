# Dropbox through Vellarin Hub

Dropbox exposes 175 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Check sharing job status
- Check save URL job status
- Check user
- Count file requests
- Download Folder as Zip
- Search files and folders
- Get about me
- Get account

**Writes (wait for the owner's approval, then run once)**
- Activate team folder
- Add file member
- Add file properties
- Add tag to file or folder
- Add folder member
- Add users to space limits exclusion list
- Add sharing allowlist
- Add members to team group

Page: https://hub.vellarin.ai/apps/dropbox
