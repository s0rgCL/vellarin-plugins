# Google Docs through Vellarin Hub

Google Docs exposes 46 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Get Drive File Metadata
- Get Spreadsheet Values
- Get document by id
- Get Document End Index
- Get document plain text
- List Drive Item Permissions
- Get Charts from Spreadsheet
- Search Documents

**Writes (wait for the owner's approval, then run once)**
- Copy Google Document
- Create and Populate Table in Google Doc
- Create a document
- Create blank document (Deprecated)
- Create Document Markdown
- Create Drive File
- Create Footer
- Create Footnote
