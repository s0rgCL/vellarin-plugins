# Google Slides through Vellarin Hub

Google Slides exposes 7 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Get Page Thumbnail v2
- Get Presentation
- Get Presentation Page
- Get Page Thumbnail (Deprecated)

**Writes (wait for the owner's approval, then run once)**
- Create Google Slides Presentation
- Create Slides from Markdown
- Update Presentation (Batch/Markdown)
- Copy Google Slides from Template

Page: https://hub.vellarin.ai/apps/googleslides
