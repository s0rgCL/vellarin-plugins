# Figma through Vellarin Hub

Figma exposes 52 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Detect Background Layers
- Discover Figma Resources
- Download Figma Images
- Extract design tokens
- Extract Prototype Interactions
- Get activity logs
- Get a webhook
- Get comments in a file

**Writes (wait for the owner's approval, then run once)**
- Add a comment to a file
- Add a reaction to a comment
- Create a webhook
- Create dev resources
- Create, modify, or delete variables
- Delete a comment
- Delete a reaction
- Delete a webhook
