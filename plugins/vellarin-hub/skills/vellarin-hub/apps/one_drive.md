# OneDrive through Vellarin Hub

OneDrive exposes 101 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Download a file
- Download file by path
- Download item as format
- Download Item Thumbnail
- Download Drive Item Version Content
- Download Thumbnail by Path
- Get document comments
- Get Drive

**Writes (wait for the owner's approval, then run once)**
- Add Workbook Worksheet
- Calculate Workbook
- Check In Drive Item
- Checkout Drive Item
- Clear Workbook Range
- Close Workbook Session
- Copy Item
- Create Drive Item Permission
