# Google Drive through Vellarin Hub

Google Drive exposes 92 actions. A sample of real action names (use `find_app_actions` for the rest):

**Reads (run at once)**
- Download a file from Google Drive
- Download file content (Deprecated)
- Download file via operation
- Download File Revision
- Find file
- Find folder
- Get about
- Get App

**Writes (wait for the owner's approval, then run once)**
- Add file sharing preference (Deprecated)
- Insert File Parent (v2)
- Insert Property (v2 API)
- Batch Get Spreadsheet Values
- Batch Update Spreadsheet Values
- Clear Spreadsheet Values
- Copy file (Deprecated)
- Copy file with advanced options

Page: https://hub.vellarin.ai/apps/googledrive
