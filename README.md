# Vellarin plugins

## vellarin-hub

Your connected business apps (Gmail, Slack, HubSpot, Google Sheets, QuickBooks and 31+ more) for Claude Code, with
human approval before anything is sent or changed, plus shared memory, a run log and eval results. One MCP server, one sign-in.

```bash
claude plugin marketplace add s0rgCL/vellarin-plugins
claude plugin install vellarin-hub@vellarin
```

The first tool call opens the Vellarin sign-in in your browser (free account at https://agents.vellarin.ai). Connect your apps there once.

- Site and docs: https://hub.vellarin.ai · https://hub.vellarin.ai/docs
- The skills alone, for claude.ai (Settings → Skills → upload): https://hub.vellarin.ai/skills/vellarin-hub.zip and https://hub.vellarin.ai/skills/vellarin-media-studio.zip
- Media Studio makes brand videos with YOUR OWN image and video generation connector; Vellarin adds the budget, the approval and the record.

Generated by `scripts/gen-hub-plugin.mjs` in the Vellarin repo; edits land there.
